The overview uses the plugin's actual signifier styling and setting controls, presented with sample note text and customized colors. The Suliworld theme supplies the general appearance. The plugin also works with other themes.

The icon and video thumbnail reuse the project's existing branding and promotional assets.

## Community-directory publication

Keep the overview embedded near the top of the main README so people opening the plugin description can see it. Publish the README and these assets together in the GitHub repository; local changes do not update the public listing.

For a dedicated screenshot in the directory, open the plugin's listing as its maintainer, choose **Edit listing**, and add `overview.png` under desktop screenshots. Add `icon.png` as the listing icon. Obsidian supports desktop screenshots at 1200 × 800, in PNG, JPEG or WebP, up to 5 MB each. See [Manage your directory entry](https://docs.obsidian.md/community-directory/manage-entry).
